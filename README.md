# יומן משפחתי

כל היומנים של המשפחה במקום אחד: היומן מהעבודה (Outlook), היומן של אמא (Google)
והחוגים של הילדים. האפליקציה רק **מציגה**. עורכים כרגיל ביומנים המקוריים, והשינויים
מופיעים כאן אוטומטית.

נפתחת בדפדפן ונשמרת במסך הבית בטלפון כמו אפליקציה רגילה (PWA), בלי App Store.

## איך זה עובד

כל יומן חושף "קישור סודי" בפורמט iCal (קובץ `.ics`). השרת מושך את הקישורים כל 10 דקות,
מאחד אותם ומציג שבוע אחד, עם צבע לכל יומן. הקישורים נשמרים רק בשרת ולא נשלחים לדפדפן,
והכניסה לאפליקציה מוגנת בסיסמה משפחתית אחת.

## שלב 1: הקישורים מהיומנים

### היומן מהעבודה (Outlook / Microsoft 365)

1. נכנסים ל-Outlook בדפדפן (outlook.office.com), לא באפליקציה המותקנת.
2. ⚙️ הגדרות ← **לוח שנה** ← **לוחות שנה משותפים** (Shared calendars).
3. תחת **פרסום לוח שנה** (Publish a calendar) בוחרים את היומן ואת רמת הפרטים:
   - **יכול להציג מתי אני עסוק**: רק "תפוס", בלי שמות של פגישות. מתאים אם לא רוצים שפרטי
     עבודה יצאו מהארגון.
   - **יכול להציג את כל הפרטים**: כולל כותרות ומיקומים.
4. לוחצים **פרסם** ומעתיקים את הקישור **ICS** (לא את ה-HTML).

> **אם אין אפשרות "פרסום לוח שנה"**, הארגון חסם אותה. אפשר לבקש מה-IT לאפשר פרסום ברמת
> "מתי אני עסוק" בלבד, וזו בקשה שבדרך כלל מאושרת. כל עוד אין קישור, האפליקציה עובדת בלי
> היומן הזה.
>
> רוצים קישור עם כל הפרטים אבל בלי להציג אותם במשפחה? מגדירים `CAL_1_PRIVATE=1`
> וכל אירוע יוצג כ"תפוס".

### היומן של אמא (Google)

1. ב-Google Calendar **במחשב** (לא באפליקציה): ⚙️ ← **הגדרות**.
2. בצד שמאל, תחת "הגדרות של היומנים שלי", בוחרים את היומן.
3. גוללים ל-**שילוב יומן** ← **כתובת סודית בפורמט iCal** ומעתיקים.

### החוגים של הילדים

הדרך הכי נוחה היא יומן Google נפרד שנקרא "חוגים":

1. ב-Google Calendar: ➕ ליד "יומנים אחרים" ← **יצירת יומן חדש** ← "חוגים".
2. משתפים אותו עם האבא עם הרשאת **ביצוע שינויים באירועים**, כדי ששניכם תוכלו לעדכן.
3. מוסיפים כל חוג כאירוע חוזר ("כל יום שלישי 16:30, חוג ציור – מאיה").
4. לוקחים את **הכתובת הסודית בפורמט iCal** שלו, כמו בסעיף הקודם.

אפשר גם יומן נפרד לכל ילד, כדי שלכל אחד יהיה צבע משלו.

> הקישורים האלה הם כמו סיסמה: כל מי שיש לו אותם רואה את היומן. אסור להכניס אותם לקוד
> או לשלוח בקבוצות. אם קישור דלף, ב-Google יש כפתור "איפוס", וב-Outlook מבטלים
> את הפרסום ומפרסמים מחדש.

## שלב 2: העלאה לאוויר (Render)

1. נכנסים ל-[render.com](https://render.com) עם חשבון GitHub.
2. **New ← Blueprint** ← בוחרים את הריפו הזה. Render קורא את `render.yaml` ויוצר את השירות.
3. ממלאים את המשתנים (Environment):

| משתנה | דוגמה | מה זה |
|---|---|---|
| `FAMILY_PASSWORD` | `pizza-tuesday-42` | הסיסמה שכולם במשפחה מקלידים פעם אחת |
| `CAL_1_NAME` | `אבא` | השם שיופיע על הכפתור |
| `CAL_1_URL` | `https://outlook.office365.com/owa/calendar/…/calendar.ics` | הקישור מ-Outlook |
| `CAL_2_NAME` | `אמא` | |
| `CAL_2_URL` | `https://calendar.google.com/calendar/ical/…/basic.ics` | הקישור מ-Google |
| `CAL_3_NAME` | `חוגים` | |
| `CAL_3_URL` | `https://calendar.google.com/calendar/ical/…/basic.ics` | יומן החוגים |

אופציונלי לכל יומן: `CAL_n_COLOR` (למשל `#16a34a`) ו-`CAL_n_PRIVATE=1` (מציג "תפוס" במקום שמות).
אפשר עד 20 יומנים, והמספרים לא חייבים להיות רצופים.

**חשוב לדעת על התוכנית החינמית ב-Render:** השרת "נרדם" אחרי רבע שעה בלי שימוש, ופתיחה
ראשונה אחרי זה לוקחת כחצי דקה עד דקה. אם זה מפריע, התוכנית Starter ($7 לחודש) תמיד ערה.

## שלב 3: התקנה בטלפון

- **אייפון:** פותחים את הכתובת ב-**Safari** ← כפתור השיתוף ← **הוסף למסך הבית**.
- **אנדרואיד:** פותחים ב-Chrome ← תפריט ⋮ ← **התקן אפליקציה**.

מקלידים את הסיסמה פעם אחת, והטלפון זוכר אותה לשנה.

## הרצה מקומית (למפתחים)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # וממלאים את הקישורים והסיסמה
uvicorn app.asgi:app --reload
```

פותחים את http://localhost:8000.

בדיקות: `pip install -r requirements-dev.txt && pytest`

## מבנה

- `app/config.py`: קריאת המשתנים (יומנים, סיסמה, אזור זמן)
- `app/feeds.py`: משיכת הקישורים, מטמון של 10 דקות, פריסת אירועים חוזרים
- `app/main.py`: השרת: כניסה בסיסמה, `GET /api/events?start=…&end=…`, והקבצים של האפליקציה
- `static/`: האפליקציה עצמה (HTML/CSS/JS בלי תלויות), כולל service worker לעבודה בלי אינטרנט

## רעיונות להמשך

- תצוגת חודש
- התראה על התנגשויות ("שניכם עסוקים כשצריך לאסוף את נועם מכדורגל")
- הוספת אירועים מתוך האפליקציה (דורש חיבור API מלא ל-Google, ול-Outlook באישור הארגון)
