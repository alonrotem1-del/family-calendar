# יומן משפחתי

כל המשפחה ביומן אחד: אמא, אבא, יולי, ליאו ורומי, כל אחד בצבע משלו.

- **אבא:** האירועים נמשכים אוטומטית מ-Outlook של העבודה.
- **אמא:** האירועים נמשכים אוטומטית מ-Google Calendar.
- **הילדים:** החוגים כתובים בקובץ [`family.yaml`](family.yaml).

האפליקציה רק **מציגה**. ממשיכים לעבוד כרגיל ב-Outlook וב-Google, וכל שינוי מופיע כאן
תוך כמה דקות. בטלפון היא נשמרת במסך הבית ונראית כמו אפליקציה רגילה, בלי App Store.

---

## מה צריך להכין לפני שמתחילים

שלושה דברים:

1. **סיסמה משפחתית.** כל מה שתבחרו, למשל `pizza-tuesday-42`. כל אחד במשפחה יקליד אותה
   פעם אחת בטלפון.
2. **קישור ליומן של אבא (Outlook).** הסבר בהמשך.
3. **קישור ליומן של אמא (Google).** הסבר בהמשך.

אפשר להתחיל גם בלי הקישורים ולהוסיף אותם אחר כך. בינתיים יופיעו רק החוגים.

### הקישור מ-Outlook (אבא)

1. נכנסים ל-Outlook **בדפדפן** בכתובת outlook.office.com, לא באפליקציה המותקנת.
2. לוחצים על ⚙️ (הגדרות) ← **לוח שנה** ← **לוחות שנה משותפים**.
3. באזור **פרסום לוח שנה** בוחרים את היומן ואת כמות הפרטים שיוצגו:
   - **"יכול להציג מתי אני עסוק"**: במשפחה יראו רק "תפוס", בלי שמות של פגישות.
   - **"יכול להציג את כל הפרטים"**: יראו גם את שם הפגישה ואת המיקום.
4. לוחצים **פרסם**. מופיעים שני קישורים, ומעתיקים את זה שנגמר ב-**`.ics`**.

**אם אין אפשרות "פרסום לוח שנה":** הארגון חסם אותה. אפשר לבקש מה-IT לאשר פרסום ברמת
"מתי אני עסוק" בלבד.

### הקישור מ-Google (אמא)

1. נכנסים ל-Google Calendar **במחשב**, כי בטלפון אין את ההגדרה הזו.
2. לוחצים על ⚙️ ← **הגדרות**.
3. בתפריט הצד, תחת "הגדרות של היומנים שלי", לוחצים על היומן של אמא.
4. גוללים למטה עד **"כתובת סודית בפורמט iCal"** ומעתיקים.

> **הקישורים האלה הם כמו סיסמה.** כל מי שמחזיק בהם רואה את היומן. לא שולחים אותם
> בוואטסאפ ולא כותבים אותם בקבצים כאן. הם נכנסים רק להגדרות ב-Render (בשלב הבא).
> אם קישור דלף: ב-Google לוחצים "איפוס" ליד הכתובת, וב-Outlook מבטלים את הפרסום
> ומפרסמים מחדש.

## העלאה לאינטרנט

**מה זה Render?** אתר שמריץ את האפליקציה בשבילנו באינטרנט, 24 שעות ביממה, ונותן לה
כתובת קבועה (משהו כמו `family-calendar-xxxx.onrender.com`) שפותחים בטלפון. יש תוכנית
חינמית.

בריפו כבר יש קובץ בשם `render.yaml` עם כל ההגדרות הטכניות. Render יודע לקרוא את הקובץ
הזה, ולכן לא צריך למלא טופס הגדרות ארוך. ב-Render האפשרות הזו נקראת **Blueprint**
("תוכנית").

### צעד אחר צעד

1. נכנסים ל-[dashboard.render.com](https://dashboard.render.com) ונרשמים עם
   **"GitHub"**. ההרשמה דרך GitHub מאפשרת ל-Render לראות את הקוד.
2. למעלה לוחצים על הכפתור **"+ New"**, ובתפריט שנפתח בוחרים **"Blueprint"**.
3. מופיעה רשימה של הריפואים שלך ב-GitHub. ליד **`family-calendar`** לוחצים **"Connect"**.
   - **לא רואים אותו ברשימה?** לוחצים על הקישור להגדרת GitHub שמופיע באותו מסך
     (Configure GitHub), ומאשרים ל-Render גישה לריפו `family-calendar`.
4. בטופס שנפתח:
   - **Blueprint Name:** כותבים `family-calendar`.
   - **Branch:** משאירים `main`.
5. Render מציג את מה שהוא עומד ליצור, ומבקש למלא שלושה ערכים:

   | שדה | מה להכניס |
   |---|---|
   | `FAMILY_PASSWORD` | הסיסמה המשפחתית |
   | `FEED_ABA` | הקישור מ-Outlook (אם עוד אין, משאירים ריק) |
   | `FEED_IMA` | הקישור מ-Google (אם עוד אין, משאירים ריק) |

6. לוחצים **"Deploy Blueprint"** ומחכים כמה דקות, עד שמופיע **"Live"** בירוק.
7. נכנסים לשירות `family-calendar`. הכתובת של האפליקציה מופיעה למעלה, מתחת לשם.

### הוספת קישור או שינוי סיסמה אחר כך

ב-Render נכנסים לשירות `family-calendar` ← **Environment** בתפריט הצד ← **Edit** ליד
המשתנה ← מדביקים ← **Save Changes**. השירות יעלה מחדש תוך דקה-שתיים.

### חשוב לדעת על התוכנית החינמית

אם אף אחד לא פתח את האפליקציה רבע שעה, השרת "נרדם". הפתיחה הבאה תיקח בערך חצי דקה
עד דקה, ומשם הכל מהיר. אם זה מפריע, התוכנית **Starter** (7$ לחודש) תמיד ערה.
מחליפים תוכנית ב-Render תחת **Settings ← Instance Type**.

## התקנה בטלפון

- **אייפון:** פותחים את הכתובת ב-**Safari** (לא בכרום) ← כפתור השיתוף (ריבוע עם חץ למעלה)
  ← **"הוסף למסך הבית"**.
- **אנדרואיד:** פותחים ב-**Chrome** ← תפריט ⋮ ← **"התקן אפליקציה"** או **"הוסף למסך הבית"**.

מקלידים את הסיסמה המשפחתית פעם אחת, והטלפון זוכר אותה לשנה.

## עדכון חוגים

החוגים כתובים בקובץ [`family.yaml`](family.yaml). יש שתי דרכים לעדכן:

- **הכי פשוט:** לבקש מ-Claude ("ליאו התחיל שחייה בימי חמישי 15:00–16:00").
- **לבד:** ב-GitHub פותחים את `family.yaml`, לוחצים על העיפרון (✏️), משנים ולוחצים
  **Commit changes**. Render יעלה את השינוי לבד תוך כמה דקות.

כך נראה חוג בקובץ:

```yaml
  - id: leo
    name: ליאו
    color: "#2563eb"
    activities:
      - title: כדורגל
        day: [שני, רביעי]
        time: "16:30-17:30"       # השעות חייבות להיות בתוך מרכאות
        location: מגרש העירוני    # לא חובה
        from: 2026-09-01          # לא חובה: מתי החוג מתחיל
        until: 2027-06-20         # לא חובה: מתי החוג נגמר
        skip: [2026-12-15]        # לא חובה: ימים בלי חוג (חגים, חופשות)
```

אם נפלה טעות בקובץ, האפליקציה לא תעלה, וב-Render תחת **Logs** תופיע הודעה בעברית
שאומרת מה הבעיה ואיפה. הגרסה הקודמת תמשיך לעבוד עד שהטעות תתוקן.

**הסתרת פרטי עבודה:** אם הקישור מ-Outlook כולל את שמות הפגישות ולא רוצים שיופיעו במשפחה,
מוסיפים לאבא בקובץ את השורה `private: true`, וכל הפגישות יוצגו כ"תפוס".

## למפתחים

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env      # ממלאים סיסמה וקישורים
uvicorn app.asgi:app --reload    # http://localhost:8000
pytest
```

- `family.yaml`: בני המשפחה, הצבעים והחוגים. לכל אחד אפשר להוסיף גם קישור ליומן
  במשתנה `FEED_` ואחריו ה-id באותיות גדולות (למשל `FEED_YULI`).
- `app/config.py`: קריאת `family.yaml` והמשתנים.
- `app/feeds.py`: משיכת הקישורים (מטמון של 10 דקות), פריסת אירועים חוזרים וחוגים.
- `app/main.py`: השרת: כניסה בסיסמה, `GET /api/people`, `GET /api/events?start=…&end=…`.
- `static/`: האפליקציה עצמה (HTML/CSS/JS), כולל service worker לעבודה בלי אינטרנט.
