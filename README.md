# יומן משפחתי

כל המשפחה במקום אחד: אמא, אבא, יולי, ליאו ורומי, כל אחד בצבע משלו. היומן של אבא מגיע
מ-Outlook של העבודה, היומן של אמא מ-Google, והחוגים של הילדים כתובים בקובץ
[`family.yaml`](family.yaml). האפליקציה רק **מציגה**. עורכים כרגיל ביומנים המקוריים,
והשינויים מופיעים כאן אוטומטית.

נפתחת בדפדפן ונשמרת במסך הבית בטלפון כמו אפליקציה רגילה (PWA), בלי App Store.

## איך זה עובד

- **[`family.yaml`](family.yaml)** מגדיר את בני המשפחה: שם, צבע, וחוגים קבועים (יום, שעות,
  מקום, מתי מתחיל ומתי נגמר, ימים בלי חוג). כדי לשנות חוג עורכים את הקובץ ב-GitHub,
  ו-Render מעלה את השינוי לבד תוך דקה-שתיים.
- **יומנים חיצוניים** (Outlook, Google) מגיעים מ"קישור סודי" בפורמט iCal (קובץ `.ics`).
  הקישור של כל אחד נשמר ב-Render במשתנה `FEED_` ואחריו ה-id שלו (`FEED_ABA`, `FEED_IMA`).
  השרת מושך אותם כל 10 דקות. הקישורים לא נכתבים בקוד ולא נשלחים לדפדפן.
- הכניסה לאפליקציה מוגנת בסיסמה משפחתית אחת.

אפשר לשלב: גם ליולי אפשר להוסיף יומן Google משלה (`FEED_YULI`) וגם חוגים בקובץ.

## שלב 1: הקישורים מהיומנים

### היומן מהעבודה (Outlook / Microsoft 365)

1. נכנסים ל-Outlook בדפדפן (outlook.office.com), לא באפליקציה המותקנת.
2. ⚙️ הגדרות ← **לוח שנה** ← **לוחות שנה משותפים** (Shared calendars).
3. תחת **פרסום לוח שנה** (Publish a calendar) בוחרים את היומן ואת רמת הפרטים:
   - **יכול להציג מתי אני עסוק**: רק "תפוס", בלי שמות של פגישות. מתאים אם לא רוצים שפרטי
     עבודה יצאו מהארגון.
   - **יכול להציג את כל הפרטים**: כולל כותרות ומיקומים.
4. לוחצים **פרסם** ומעתיקים את הקישור **ICS** (לא את ה-HTML).

> **אם אין אפשרות "פרסום לוח שנה"**, הארגון חסם אותה. אפשר לבקש מה-IT לאפשר פרסום ברמת
> "מתי אני עסוק" בלבד, וזו בקשה שבדרך כלל מאושרת. כל עוד אין קישור, האפליקציה עובדת בלי
> היומן הזה.
>
> רוצים קישור עם כל הפרטים אבל בלי להציג אותם במשפחה? מוסיפים `private: true`
> לאבא ב-`family.yaml`, וכל אירוע יוצג כ"תפוס".

### היומן של אמא (Google)

1. ב-Google Calendar **במחשב** (לא באפליקציה): ⚙️ ← **הגדרות**.
2. בצד שמאל, תחת "הגדרות של היומנים שלי", בוחרים את היומן.
3. גוללים ל-**שילוב יומן** ← **כתובת סודית בפורמט iCal** ומעתיקים.

### החוגים של הילדים

החוגים לא צריכים קישור, כי הם כתובים ב-[`family.yaml`](family.yaml) תחת כל ילד:

```yaml
  - id: leo
    name: ליאו
    color: "#2563eb"
    activities:
      - title: כדורגל
        day: [שני, רביעי]
        time: "16:30-17:30"       # עם מרכאות!
        location: מגרש העירוני
        from: 2026-09-01
        until: 2027-06-20
        skip: [2026-12-15]        # חנוכה, חופשות וכו'
```

אם יש טעות בקובץ, הבדיקות האוטומטיות וגם השרת עצמו יגידו בעברית מה ואיפה.

> הקישורים האלה הם כמו סיסמה: כל מי שיש לו אותם רואה את היומן. אסור להכניס אותם לקוד
> או לשלוח בקבוצות. אם קישור דלף, ב-Google יש כפתור "איפוס", וב-Outlook מבטלים
> את הפרסום ומפרסמים מחדש.

## שלב 2: העלאה לאוויר (Render)

1. נכנסים ל-[render.com](https://render.com) עם חשבון GitHub.
2. **New ← Blueprint** ← בוחרים את הריפו הזה. Render קורא את `render.yaml` ויוצר את השירות.
3. ממלאים את המשתנים (Environment):

| משתנה | דוגמה | מה זה |
|---|---|---|
| `FAMILY_PASSWORD` | `pizza-tuesday-42` | הסיסמה שכולם במשפחה מקלידים פעם אחת |
| `FEED_ABA` | `https://outlook.office365.com/owa/calendar/…/calendar.ics` | הקישור מ-Outlook של אבא |
| `FEED_IMA` | `https://calendar.google.com/calendar/ical/…/basic.ics` | הקישור מ-Google של אמא |

מי שעוד אין לו קישור פשוט נשאר ריק, והאפליקציה עובדת בלעדיו.

**חשוב לדעת על התוכנית החינמית ב-Render:** השרת "נרדם" אחרי רבע שעה בלי שימוש, ופתיחה
ראשונה אחרי זה לוקחת כחצי דקה עד דקה. אם זה מפריע, התוכנית Starter ($7 לחודש) תמיד ערה.

## שלב 3: התקנה בטלפון

- **אייפון:** פותחים את הכתובת ב-**Safari** ← כפתור השיתוף ← **הוסף למסך הבית**.
- **אנדרואיד:** פותחים ב-Chrome ← תפריט ⋮ ← **התקן אפליקציה**.

מקלידים את הסיסמה פעם אחת, והטלפון זוכר אותה לשנה.

## הרצה מקומית (למפתחים)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # וממלאים את הקישורים והסיסמה
uvicorn app.asgi:app --reload
```

פותחים את http://localhost:8000.

בדיקות: `pip install -r requirements-dev.txt && pytest`

## מבנה

- `family.yaml`: בני המשפחה, הצבעים והחוגים
- `app/config.py`: קריאת `family.yaml` והמשתנים (קישורים, סיסמה, אזור זמן)
- `app/feeds.py`: משיכת הקישורים, מטמון של 10 דקות, פריסת אירועים חוזרים וחוגים
- `app/main.py`: השרת: כניסה בסיסמה, `GET /api/people`, `GET /api/events?start=…&end=…`, והקבצים של האפליקציה
- `static/`: האפליקציה עצמה (HTML/CSS/JS בלי תלויות), כולל service worker לעבודה בלי אינטרנט

## רעיונות להמשך

- תצוגת חודש
- התראה על התנגשויות ("שניכם עסוקים כשצריך לאסוף את נועם מכדורגל")
- הוספת אירועים מתוך האפליקציה (דורש חיבור API מלא ל-Google, ול-Outlook באישור הארגון)
